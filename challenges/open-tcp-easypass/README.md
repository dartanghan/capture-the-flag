Um desenvolvedor estava criando um serviço no servidor da companhia.
Durante os testes, ele equivocadamente colou a senha do usuário Root num arquivo em que ele estava trabalhando.

Existe o risco de o sistema estar exibindo esta senha em alguma porta do servidor.

- Descubra se existem portas abertas no servidor.
- Se existir, descubra o que elas retornam.
- Se existir e retornarem, tente acessar como root o servidor usando a chave como senha.
- Descubra onde o arquivo de senha está e remova-o.
- Garanta que a senha deixou de ser exibida.
- Tire um print de seu acesso e compartilhe com a turma.

OBS: O servidor reinicia a cada 30 minutos.
